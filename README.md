### Literate programming on Linear Algebra

A set of jupyter notebooks for tinkering and playing with LateX, Python and the corpus of Linear Algebra, mainly folling lessons and books from Gilbert Strand. 


### Project setup

1. Clone project from GitHub.com

2. Download packages and create .venv with:

`$ uv sync`

3. run jupyter lab with:

`$ uv run jupyter lab`

4. when running from Omarchy and have a Web App set up to point to localhost:8888/lab, run with:

`$ uv run jupyter lab`

and launch the Omarchy Web App afterwards.

The project is designed not to need any .venv activation, you should not need it, uv run should do.
